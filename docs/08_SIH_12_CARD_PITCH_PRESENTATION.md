```
# Card 6: How We Verify Real Code (GitHub Evidence Engine)
*We do not count stars or commits. We inspect syntax trees and manifests.*

### Multi-Stage Code Inspection Pipeline:
```
Selected Repository ──► Manifest Inspector ──► AST Parser ──► Evidence Extractor ──► Skill Evidence

```
# Card 7: Adaptive Technical Assessment
*Self-ratings are hypotheses. Adaptive assessments verify them.*

### Multi-Format Question Engine:
* **MCQ**: Core algorithmic data structures & Big-O complexity
* **Assertion–Reason**: Deep conceptual causality (e.g. dictionary hash probing)
* **Code Output**: Execution trace & closure evaluation
* **Debugging**: Identifying root-cause bugs in broken configuration/snippets
* **Scenario-Based**: System bottlenecks (e.g. 10,000 req/min database triage)
* **Architecture**: Production schema design, caching & connection pooling

### Adaptive Calibration Loop:
```
Candidate Claims: "Python Advanced"
            │
            ▼
[LEVEL 1: CORE SYNTAX] ────────► Passed (Functions, OOP, Scopes)
            │
            ▼
[LEVEL 2: ASYNC CONCURRENCY] ──► Passed (Event loop, async/await non-blocking)
            │
            ▼
[LEVEL 3: SYSTEM ARCHITECTURE] ─► Incomplete (Connection pools, memory leaks)
            │
            ▼
[CALIBRATED OUTCOME]
Evidence-Based Level: Intermediate | Confidence: High
```

> **Transparent Rationale**: Final proficiency is a deterministic synthesis of Resume Claim + Code AST + Self-Rating + Assessment Score.

# Card 9: Prerequisite-Aware Topological Roadmap
*Don't attempt cloud orchestration before mastering containers.*

### Canonical Prerequisite DAG (NetworkX & Kahn's Topological Sort):
```
[Linux Fundamentals] ──────► [Docker Containerization] ──────► [AWS ECS Deployment]
        ▲                                 ▲                                 ▲
        │ (Cleared)                       │ (Active Gap)                    │ (Locked Goal)
[Git Version Control] ─────► [PostgreSQL & Indexing] ──────► [Kubernetes Cluster]
```

### Dynamic Node Classification:
* 🟢 **Demonstrated / Cleared**: Automatically skipped in the roadmap so students never repeat what they already proved.
* 🟡 **Active Prerequisite Gap**: The exact next conceptual foundation the candidate is unblocked to master.
* ⚪ **Locked Dependent Goal**: Advanced tools locked until their foundational prerequisites are demonstrated.
```
