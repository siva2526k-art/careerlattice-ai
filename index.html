📜 Terms & Conditions & Data Processing Consent

CareerLattice AI is grounded in transparent, evidence-based verification. Before collecting technical data, we require explicit authorization.

1. Evidence-Based Verification: CareerLattice analyzes claimed technical competencies against empirical artifacts. A resume represents a claim; inspected code and technical assessments constitute evidence.

2. GitHub Repository Inspection: The platform reads ONLY repositories explicitly selected by the student. It analyzes file manifests (e.g. requirements.txt, Dockerfile) and abstract syntax trees (ASTs) for imports and module patterns. No private repository is accessed without authorization.

3. Adaptive Assessments: Technical answers are evaluated dynamically to calibrate proficiency levels. All feedback is deterministic and explainable.

4. Data Privacy: Your resumes, PII, and credentials are encrypted. Tokens and API keys are stored server-side only and never exposed to client browsers.

5. "Not Verified" Distinction: A rating of "Not Verified" indicates insufficient evidence was detected; it does NOT assert that the candidate lacks the skill.
